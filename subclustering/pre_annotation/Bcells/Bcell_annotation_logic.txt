STEP 2 - ANNOTATION: retained subclusters and the reasoning for each
-------------------------------------------------------------------------------

Subcluster 0  -> "Naive B (IEG-high)"          [confidence: MEDIUM]
  Naive identity:
    IGHD+, FCER2/CD23+ (= 0.82 scaled), CD27- (= 0.00), ADT CD1D high.
  Distinguishing program:
    Strong immediate-early + heat-shock signature -- FOS, FOSB, GADD45B, DUSP1,
    DNAJB1, DNAJA1, HSPH1, HSP90AA1, PER1.
  Interpretation:
    Naive B carrying an activation / dissociation-stress program rather than a
    distinct lineage. The IEG/HSP genes are classic ex-vivo handling artifacts.
  VERIFY:
    Check whether this cluster is restricted to particular donors or a batch.
    If yes -> treat as technical (consider merging into resting naive). If it is
    spread evenly, it may reflect genuine recent in-vivo activation.

Subcluster 1  -> "Naive B (resting)"           [confidence: HIGH]
  Evidence:
    IGHD = max, FCER2/CD23 = max, SELL+ (also a top marker), CD27- (= 0.00),
    TCL1A+. DSP, IGFBP4 among top markers. No activation/stress program.
  Interpretation:
    Textbook resting naive B -- the core naive population of the compartment.

Subcluster 2  -> "Memory B"                     [confidence: HIGH]
  Evidence:
    CD27 = max, TNFRSF13B (TACI) = max, CD80 = max, plus CD70, FAS, TEX9, TFEC,
    S100A4. ADT: CD27 high, CD24 high; also CD82 (top ADT marker).
  Interpretation:
    CD27+ TACI+ CD80+ = activated / switched memory B cells. FCRL4 is also high
    here, sometimes seen in tissue-like / atypical memory, but in PBMC the CD27+
    program dominates -> memory B.

Subcluster 3  -> "Intermediate B (HLA-G+)"      [confidence: MEDIUM]
  Evidence:
    Intermediate CD27 (= 0.59), FCRL4 high (= 0.92). Distinctive HLA-G and
    HLA-DQA2 program (HLA-G = top RNA marker). ADT: BAFF-R (TNFRSF13C) very high
    (top ADT marker by a wide margin), with BTLA, CXCR3, IGHM, CD79B.
  Interpretation:
    Unswitched / intermediate B (between naive and memory). The HLA-G+ phenotype
    has been described for a regulatory-leaning B subset.
  VERIFY:
    Look at IL10 and CD5 to test whether a Breg (regulatory B) label is warranted
    rather than generic intermediate/unswitched.

Subcluster 4  -> "Transitional B"               [confidence: HIGH]
  Evidence:
    TCL1A = max, MZB1 = max, PAX5 = max, IGHD+; FCRL1 a top marker; ADT CD24 and
    CD38 elevated.
  Interpretation:
    TCL1A-hi MZB1-hi CD24-hi CD38-hi is the canonical transitional B signature.
    This is the transitional core (consistent with parent Cluster_ID 12).

Subcluster 5  -> "Atypical B (ABC / DN2)"       [confidence: HIGH]
  Evidence:
    TBX21 (T-bet) = max, ITGAX (CD11c) = max, FCRL5 = max, ZEB2 = max, FGR = max,
    TOX2, CD86, NKG7, IGHG2 (class-switched). ADT: CD11c (ITGAX), CD86, CD22 high.
    Largest set of significant markers (~900) -> transcriptionally very distinct.
  Interpretation:
    Unambiguous age-associated / atypical B cell (ABC, "DN2"). T-bet+ CD11c+
    FCRL5+ ZEB2+ is the defining combination. Of biological interest in
    HIV/chronic-stimulation settings.

Subcluster 8  -> "Transitional/Naive (T2-like)" [confidence: MEDIUM]
  Evidence:
    TCL1A+ (= 0.76), IGHD+, PAX5+, ROR1+ (ROR1 a top marker), HLA-DRB5, IL3RA.
    ADT: CD38 high (= max), CD21/CR2 high (= max), IGHD high (= max).
  Interpretation:
    Sits between transitional and naive -- a later (T2/T3) transitional or
    early-naive stage. CR2(CD21)-hi with retained CD38 is consistent with a
    maturing transitional cell approaching the naive pool.
  VERIFY:
    Compare CD24/CD38 co-levels against subcluster 4 to position it on the
    T1 -> T2 -> naive axis; if indistinguishable from 4, consider merging.
